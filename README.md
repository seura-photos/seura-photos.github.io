# Seura Photos website

The home page and devlog of [Seura Photos](https://github.com/seura-photos/seura), a free, open-source photo app for Windows and macOS. Published at https://seura-photos.github.io.

Built with [Astro](https://astro.build). `npm ci && npm run dev` to run it locally; pushing to `main` publishes it through GitHub Actions.
